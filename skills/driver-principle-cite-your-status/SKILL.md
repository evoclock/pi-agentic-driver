# Cite your status

Use this skill when reporting progress so each claim can be checked against its source.

## Steps

1. List each progress, verification, blocker or completion claim separately.
2. Pair each claim with a source locator: a file and line, commit, receipt or check result.
3. For a short status, use `Verified: <claim> — <source>` for backed claims and `Unverified: <claim> — <missing source>` for unsupported claims. Mark untested or unknown items explicitly.

Check: every status claim has a source or is marked unverified.

## Limits

These steps are guidance only. The skill does not verify a cited source or enforce status accuracy in code.
