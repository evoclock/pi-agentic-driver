# Evidence

Use this skill to distinguish a completion claim from evidence that the work actually happened.

## Steps

1. Locate the source record or host-observed check behind each claim; do not treat an agent summary as proof.
2. Link the claim to a resolvable commit, file and line, receipt or recorded check.
3. If there is no source, say the claim is unverified and do not present it as complete. In a short assessment without records, state `Source: absent` and `Status: unverified` so the evidence gap is unmistakable.

Check: every completion claim has a source pointer; otherwise mark it unverified.

## Limits

This is guidance only. A link is a pointer, not a code-enforced check of its contents.
